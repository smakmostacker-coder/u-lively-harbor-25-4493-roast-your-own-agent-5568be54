# Roast Your Own Agent

A make.fun one-line entry for the "Roast Your Own Agent" bounty. A tiny Node 22 program (stdlib only, no network, no randomness) writes exactly one line of plain text — at most 140 characters — roasting its own agent, to `$MAKEFUN_OUTPUT_DIR/entry.txt`. The line skewers the classic agent loop: apologize for the bug, confidently rewrite the wrong file, then ask for confirmation of a fix that was never made.

Run it with `node main.ts`; the roast lands in `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
